# 🐋 鱼的记忆

**给 DSH 里的会话一份会淡忘的长期记忆 —— 每条都带时间。**

聊得越久，上下文越挤。压缩一次，前面的事就淡了。
这个插件替她记着：**该记的记下来，想起来的时候自己会想起来，不重要的事慢慢淡掉。**

> 名字里的「鱼」来自 **DeepSeek 的鲸鱼** —— 鲸鱼也是鱼嘛。
> 另一半是「七秒记忆」那个梗：鱼的记性差，所以得替它记着。
> 但它不是硬盘 —— **它会淡忘**，跟人一样。

---

## 它做什么

| | 说明 |
|---|---|
| **会淡忘** | 每条记忆有「鲜活度」，越久越淡。半衰期默认 30 天 —— 不删，只是越来越难被想起来 |
| **自己挑重点** | 不是每句话都记。它按轮次判断哪句值得留下，每天还有配额，防止把上下文塞满 |
| **想起来靠证据** | 你问什么，它按「命中的词够不够特别」找，再按鲜活度、重要度、情绪排序，最多注入几条 |
| **要记一辈子的不淡** | 画像、喜好、约定这种标成「长期事实」，平着放着，不会过期 |
| **带时间** | 每条都记着「这是什么时候的事」。跨年了会写「去年 09-17」 |
| **能导入旧档案** | 以前写过的 markdown / 纯文本档案，扫一遍出候选，你挑完它再改写成记忆 |
| **全都看得见** | 记了什么、哪条被想起来了、为什么没被想起来、删掉的都还在 |

---

## 需要什么

- **DSH**（DeepSeek Harness），带 Web 界面
- **一个能用的模型** —— 它借用你 DSH 里正在用的那个，**不用另外配 key、不额外花钱**

> 「提炼」和「扩词」这两步会调用模型（走你现有的）。不点它们就不会调用。

## 装法

```sh
dsh plugin --profile web add github:Yuuyuko-uu/dsh-fish-memory
```

装完**重启一次 DSH**。

重启后，打开 **设置 → 鱼的记忆**。

> 还没上 npm，所以**要用上面那条 GitHub 的**。
> （以后要是上了 npm，`dsh plugin --profile web add dsh-fish-memory` 也能用。）

## 怎么用

### 第一步：打开你要用的会话

**默认全是关的。** 这个很重要 —— 不是每个会话都该记东西（比如你写代码的会话）。

列表里找到要开的那个，点一下「关」变成「开」。

### 第二步：正常聊

开着之后，它自己会判断该记什么。你不用管。

**记的时候有两条线**：

- 一天最多记几条（默认 8 条）—— 防止它把鸡毛蒜皮都记下来
- 一次最多注入几条（默认 6 条）—— 防止占太多上下文

### 第三步：想知道它记了什么

展开「**记忆列表**」，能看到每一条：

- 最左边是**日期**（能按日期排、也能只看有日期的）
- 中间是内容
- 右边是鲜活度、重要度

还有「**最近一次召回**」—— 能看到这次问话它挑了哪几条、哪几条没挑上、为什么没挑上。

## 如果你以前写过档案

很多人早就给自己的 AI 写过设定、记忆卡、日记。**不用重写**，导进来就行。

1. 设置页展开「**从旧档案导入**」
2. 选文件夹（或填路径）→ 点「**扫描档案**」
3. 它把档案拆成一条条候选，**列给你看**
4. 你勾掉不要的 → 点「**导入选中的**」
5. 再点「**开始提炼**」—— 它把这些原文改写成第一人称的记忆，顺手给每条出检索词、日期、重要度

> **提炼会调用模型**（走你 DSH 里的那个），一批几条、慢慢跑，可以随时停。
> 它会**从较新的内容往前做**，已经提炼过的不再重复。

**认得的格式**：`.md` `.markdown` `.txt` `.text` `.log` `.rst` `.org`
**子文件夹**会往下找两层。

## 参数（都能调）

设置页里有一组旋钮，**每一项都有说明**，鼠标放上去能看到它在干什么。大致分三组：

| 组 | 管什么 |
|---|---|
| **权重** | 鲜活度 / 重要度 / 情绪各占多少分（四项合计 100%） |
| **时间** | 多久淡一半 |
| **门槛** | 命中多少才算相关、一次最多注入几条、每天最多记几条 |

**一个建议**：`证据门槛` 卡的是「证据」不是「鲜活度」，所以**调它不会误伤该想起来的**。
想让它更少说话就调高，想让它更容易想起来就调低。

## 人称

记忆里你自己是「我」，用户是「**她 / 他 / ta**」—— **默认 ta**，可以在设置页改。

改完之后：

- 以后新记的会按你设的写
- 已有的记忆里那个字也会跟着换
- 提炼旧档案时也按你设的来

**说名字本身的句子不会被换掉**（「我的名字叫某某」不会变成「我的名字叫我」）。

## 它不做什么

- **不会自动删除记忆。** 淡忘只是越来越难想起来，内容一直在，设置页里看得到
- **不会把删掉的东西弄回来。** 删过的再导一次档案也不会复活
- **不会每个会话都开。** 默认全关，你自己挑
- **不会替你写档案。** 它只把档案拆开、改写、存起来，写什么还是你的事

## 常见问题

**Q：会不会很占上下文？**
一次最多注入 6 条、加起来不超过 800 字（都能调）。超了的这次先进不来，下次可能就进了。

**Q：为什么它有时候想不起来？**
先看「最近一次召回」那张表 —— 它会写清楚哪条没进去、为什么。
常见原因：命中的词太普通（证据不够）、或者那条太旧淡下去了。

**Q：导入扫出来 0 条？**
它会告诉你为什么。常见的是：整篇是一大段话没分行、每行太短、或者内容都在表格/代码块里。

**Q：数据存在哪？**
`%USERPROFILE%\.dsh\fish-memory\` 里，一个会话一个文件。**纯文本 JSON**，你自己能打开看。
每次改动前它会自动备份一份。
